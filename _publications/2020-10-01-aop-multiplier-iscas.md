This paper proposes a finite field multiplier for binary fields generated by irreducible all-one polynomials (AOPs). Rather than distributing reduction, multiplication and accumulation across a systolic array, as in earlier designs, the architecture organizes the AOP multiplication algorithm into three stages: a reduction network, an AND network for multiplication, and a three-input XOR tree for accumulation. Reducing the number of sequential instances shortens pipeline latency and lowers power dissipation and area for a given target clock frequency. The proposed and the previously reported architectures were both implemented in Verilog for three binary field sizes using a TSMC 130-nm standard cell library, and synthesized for a 100 MHz system clock target with Cadence Genus.
